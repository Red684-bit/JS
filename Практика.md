# Создание списка задач на Vue 3

## 0. Подготовка окружения

Инициализируйте новый проект на Vue 3 в Вашей рабочей среде.

## 1. Управление состоянием

В Vue 3 состояние компонента объявляется внутри скрипта. Для изменяемых данных требуется использовать специальную функцию реактивности.

**Задание:**
1.  Импортируйте функцию для создания реактивных ссылок и функцию для вычисляемых свойств из основной библиотеки Vue.
2.  Объявите переменную-счетчик для уникальных идентификаторов задач (id).
3.  Создайте реактивную переменную для хранения текста, вводимого пользователем в поле создания задачи.
4.  Создайте реактивный массив, содержащий начальный список задач. Каждая задача должна быть объектом, содержащим идентификатор, текст и статус выполнения.

> **Подсказка по синтаксису:**
> *   Для создания реактивных переменных используется функция `ref`.
> *   Для доступа к значению реактивной переменной внутри скрипта необходимо обращаться к свойству `.value`.

## 2. Верстка формы ввода

Необходимо создать интерфейс для добавления новых задач. Использование тега формы позволяет корректно обрабатывать нажатие клавиши ввода.

**Задание:**
1.  Создайте элемент формы в шаблоне компонента (тег form).
2.  Добавьте поле ввода текста внутри формы (тег input). Двухсторонне свяжите его значение с переменной текста задачи, созданной на предыдущем шаге.
3.  Добавьте кнопку отправки формы с подписью для создания задачи.
4.  Настройте обработчик события отправки формы таким образом, чтобы страница не перезагружалась, а вызывалась функция добавления задачи.

> **Подсказка по синтаксису:**
> *   Для двусторонней связи данных используется директива `v-model`.
> *   Для обработки событий используется символ `@` (сокращение от `v-on`).
> *   Для предотвращения стандартного поведения браузера (перезагрузки) используйте модификатор события `.prevent`.

## 3. Отображение списка задач

Для вывода списка необходимо использовать директиву цикла.

**Задание:**
1.  Создайте маркированный список в шаблоне.
2.  Настройте цикл для перебора массива задач.
3.  Для каждого элемента списка обязательно укажите уникальный ключ, используя идентификатор задачи.

> **Подсказка по синтаксису:**
> *   Для рендеринга списка используется директива `v-for`.
> *   Для указания уникального идентификатора элемента используется директива `:key` (сокращение от `v-bind:key`).

## 4. Интерактивность элементов списка

Каждая задача должна позволять пользователю отмечать выполнение и удалять себя из списка.

**Задание:**
1.  Внутри элемента списка добавьте поле выбора (чекбокс). Свяжите его состояние со статусом выполнения конкретной задачи.
2.  Добавьте текстовый элемент для отображения названия задачи.
3.  Настройте динамическое применение стиля зачеркивания текста, если задача отмечена как выполненная.

> **Подсказка по синтаксису:**
> *   Для динамического изменения классов используется директива `:class`.
> *   Для вывода текста переменных используется интерполяция в фигурных скобках `{{ }}`.

## 5. Логика добавления и удаления

Реализуйте функции для изменения состояния списка внутри скрипта.

**Задание:**
1.  Создайте функцию добавления задачи. Она должна создавать новый объект задачи с уникальным идентификатором, добавлять его в массив и очищать поле ввода текста. Добавьте проверку, чтобы нельзя было добавить пустую задачу.
2.  Добавьте кнопку удаления рядом с задачей ( Х ). Настройте её так, чтобы при клике вызывалась функция удаления, передающая текущую задачу как аргумент. Она должна обновлять массив задач, исключая из него элемент, переданный в качестве аргумента.

> **Подсказка по синтаксису:**
> *   Для добавления элемента в реактивный массив можно использовать метод `.push`.
> *   Для удаления элемента удобно использовать метод массива `.filter`, создавая новый массив без удаляемого элемента.
> * Пример: array = array.filter(v => v != someValue)

## 6. Фильтрация задач

Для скрытия выполненных задач рекомендуется использовать вычисляемые свойства, так как они кэшируются и зависят от реактивных данных.

**Задание:**
1.  Создайте реактивную булевую переменную-флаг, которая будет отвечать за скрытие или отображение выполненных задач.
2.  Создайте вычисляемое свойство, которое возвращает список задач.
3.  Реализуйте логику: если флаг скрытия выполнен включен, свойство должно возвращать только незавершенные задачи. В противном случае — весь список.
4.  В шаблоне замените перебор основного массива задач на перебор этого вычисляемого свойства.
5.  Добавьте кнопку переключения режима отображения, которая меняет значение флага скрытия на противоположное. Текст кнопки должен меняться в зависимости от текущего состояния флага.

> **Подсказка по синтаксису:**
> *   Для создания вычисляемого свойства используется функция `computed`, принимающая стрелочную функцию.
> *   Внутри шаблона вычисляемые свойства используются как обычные переменные.

## 7. Улучшение функциональности

Для повышения удобства использования предлагается внедрить следующие дополнения:

**Задание 1: Счетчик активных задач**
1.  Создайте еще одно вычисляемое свойство, которое подсчитывает количество задач, не отмеченных как выполненные.
2.  Выведите это количество в шаблоне под списком задач.

**Задание 2: Массовая очистка**
1.  Создайте функцию, которая удаляет из массива все задачи, отмеченные как выполненные.
2.  Добавьте кнопку для вызова этой функции.
3.  Сделайте эту кнопку неактивной, если выполненных задач нет.

> **Подсказка по синтаксису:**
> *   Для подсчета элементов можно использовать метод `.filter` и свойство `.length`.
> *   Для блокировки элемента интерфейса используйте привязку атрибута `:disabled`.
